# 台股 15 大核心指標監控儀表板 · TW Markets

以 TradingView Markets 的資訊層級為參考：白底、粗體標題、指數切換、大幅走勢、橫向行情卡與市場排行。所有資料去蕪存菁，整合為聚焦於 **15 大核心指標** 的連續面版系統。

## 15 大核心指標

| 編號 | 指標名稱 | 取得或計算的資訊 |
|---|---|---|
| **01** | **市場趨勢** | 加權、櫃買指數的 OHLC、20／60／120 日均線、前高前低點位與防守狀態 |
| **02** | **趨勢偏離程度** | 20／60 日均線乖離率、近期最大回撤 (60D/120D Drawdown)、ATR14 真實波幅 |
| **03** | **漲跌家數** | 上漲家數、下跌家數、平盤、漲停/跌停、漲跌家數比及累積騰落指標 (A/D Line) |
| **04** | **均線廣度** | 上市＋上櫃全市場股票站上 20／60／120 日均線的真實比例 (%) |
| **05** | **新高／新低廣度** | 創 52 週新高、新低的家數及其 5 日擴張／收縮淨變化 |
| **06** | **市場成交值** | 上市、上櫃股票成交值及相對 20 日均值倍數 (Volume Ratio vs 20MA) |
| **07** | **量價反應** | 放量突破、放量不漲、放量下跌、跌深後放量止跌等四大量價結構情境自動診斷 |
| **08** | **融資餘額** | 上市、上櫃融資餘額及 5／20 日增減額、增減率、融資現金償還與融券 |
| **09** | **槓桿清洗程度** | 融資從近期波段高點回落幅度、融資變化率與股價變化率之差額 (去槓桿品質) |
| **10** | **領漲族群** | 30+ 產業相對大盤強度 (Alpha vs TAIEX)、漲幅貢獻、領漲族群數量統計 |
| **11** | **強勢股健康程度** | 原先領先權值股相對強弱、跌破關鍵均線 (MA20/MA60) 或補跌重挫之比例 |
| **12** | **恐慌程度** | 臺指選擇權波動率指數（臺指 VIX）及歷史百分位、美股 Cboe VIX、VVIX 對照 |
| **13** | **法人與資金動向** | 外資現貨單日／累計買賣超、臺股期貨外資淨未平倉部位 (Net OI)、Put/Call Ratio |
| **14** | **基本面變化** | 上市櫃月營收趨勢 (YoY/MoM)、主要產業 EPS 最新統計及修正方向 |
| **15** | **估值與預期** | 全市場 Trailing P/E、Forward P/E、歷史估值百分位、預期獲利成長率與 PEG |

## 內容與面版架構

- **15 指標即時監控總覽**：頁首 15 格核心矩陣卡片，一眼掌握全部指標當前數值、多空狀態與一鍵直達錨點。
- **01 趨勢與偏離**：加權與櫃買指數歷史日線、成交值、K 線／均線切換、拖曳區間報酬量測、均線乖離率與波段回撤。
- **02 廣度與動能**：全市場漲跌比率彩色條、累積 A/D Line 趨勢、站上月線/季線/半年線廣度計、52 週新高新低擴張。
- **03 成交量價**：上市櫃成交值與 20MA 倍數、量能水位、突破/滯漲/下殺/止跌量價反應情境量化。
- **04 融資槓桿**：上市櫃融資餘額趨勢圖、5/20日增減速、融資高點回落幅度與去槓桿差額診斷。
- **05 族群強勢股**：各產業類股相對大盤 Alpha 排行、領跑族群數、科技權值股跌破月季線與補跌健康度評分。
- **06 恐慌與法人**：期交所臺指 VIX 走勢與歷史分位、外資現貨買賣超、台指期外資淨未平倉留倉口數。
- **07 基本面估值**：全市場營收中位成長率、主要產業 EPS 成長方向、Forward P/E 與 PEG 評價位階。
- **資料來源與更新**：各來源狀態、最後觀測日、排程與連線監控；支援手機響應式版型與淺色／深色模式。

## 資料與排程

純靜態 GitHub Pages 架構。GitHub Actions 自動執行 `scripts/update_market.py` 產生包含 15 項計算指標的 `data/market.json` 快照。

| 資料 | 台北時間排程 |
| --- | --- |
| 台股盤中指數 | 交易日 09:00–13:30，每 10 分鐘 |
| 台股盤後、技術、籌碼、營收與公告 | 交易日 15:30 |
| 海外收盤、VIX、美債 | 06:00，依工作流程平日 UTC 排程 |

## 本地預覽與驗證

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

```sh
node --test tests/*.test.mjs
node --check assets/market.js
python3 scripts/update_market.py --mode full
```

## 檔案架構

- `index.html`：單頁儀表板入口與面版結構。
- `assets/market.css`：TradingView 風格版型、15 指標矩陣與響應式樣式。
- `assets/market.js`：15 大指標視覺化呈現、互動與圖表繪製調度。
- `assets/model.mjs`：指標提取、數值格式化與防護計算。
- `assets/charts.mjs`：SVG K 線、均線、成交量與走勢圖繪製。
- `scripts/update_market.py`：GitHub Actions 後端資料抓取主腳本。
- `scripts/indicators.py`：15 大核心指標量化計算引擎。
- `tests/market.test.mjs`：前端邏輯與 15 大指標完整性單元測試。
